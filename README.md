\# 💊 MediTrack — Medicine Expiry \& Availability Tracker



\## Overview

MediTrack is a Python-based inventory management dashboard designed to track medicine batches, quantities, expiry dates, and stock availability.



\## Features

\- Add medicine batches with batch numbers and expiry dates

\- Search medicine inventory

\- Update and delete medicine records

\- Identify expired and soon-to-expire batches

\- Generate low-stock alerts

\- Visualize expiry status using a dashboard chart

\- Download inventory records as CSV



\## Tech Stack

\- Python

\- Streamlit

\- Pandas

\- CSV data storage



\## How to Run

1\. Clone or download this repository.

2\. Install dependencies:

&#x20;  `pip install -r requirements.txt`

3\. Run the application:

&#x20;  `streamlit run app.py`

4\. Open the local URL displayed in your terminal.



\## Project Purpose

This project demonstrates data handling, data validation, inventory tracking, alert logic, and interactive dashboard development.



\## Disclaimer

This is an educational prototype, not a validated pharmacy management system. Verify all inventory and expiry information before making real-world decisions.
